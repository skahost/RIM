# SKA Theme for Pterodactyl

A blueprint-ready extension pack for Pterodactyl-themed panel installs, designed to work cleanly with modern Arix-based setups and Pterodactyl 1.14.x style layouts.

## Features
- Registration flow with first/last name, email, username, and password fields
- SKA branding and custom footer support
- Server-side plugin and mod installers
- Lightweight blueprint extensions for:
  - subdomain management
  - MOTD maker
  - version changer
  - auto suspension
- One-command installer for the theme extension bundle

## One-line installer

Run this from the project root:

```bash
bash <(curl -fsSL https://raw.githubusercontent.com/skahost/RIM/main/install-ska-theme.sh)
```

## Manual install

1. Copy the theme folder into your panel installation.
2. Run the installer script.
3. Clear caches and rebuild assets if required.

## Notes
- This package is intended for Arix-based theme customization work and Pterodactyl 1.14.x-compatible layouts.
- Review the admin editor after installation to enable or disable individual blueprints.
